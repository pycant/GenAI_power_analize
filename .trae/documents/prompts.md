 # 2.5 文本摘要任务 (summary)  ## 评估目标 评估模型生成摘要在**信息保留程度、简洁性、流畅性与语义正确性**上的表现。  ---  ## 核心指标  ### 1. ROUGE-L - **定义**：基于**最长公共子序列（LCS）**计算的 F1 分数。 - **计算**：通过预测摘要与参考摘要的最长公共子序列，计算精确率、召回率与 F1。 - **范围**：[0, 1] - **优势**：关注**语序与结构完整性**，是摘要任务最经典的核心指标。  ### 2. BERTScore - **定义**：基于预训练语言模型 BERT 的上下文语义相似度。 - **计算**：使用 BERT 得到词向量，计算预测与参考摘要间的余弦相似度，得到语义级 F1。 - **范围**：[0, 1] - **优势**：能识别**同义不同表述**，更贴合人类对摘要的语义理解。  ### 3. BARTScore - **定义**：基于 BAR 模型的**双向生成概率打分**。 - **计算**：   - \(P(\text{summary}|\text{source})\)   - \(P(\text{source}|\text{summary})\) - **范围**：\((-\infty, 0]\)，**数值越大表示质量越高**。 - **优势**：同时衡量**忠实度与相关性**，是目前最接近人类评分的自动指标之一。  ---  ## 辅助指标  ### 4. 压缩比 (Compression Ratio) - **定义**：摘要简洁性的量化指标。 - **计算**： \[ \text{压缩比} = \frac{\text{摘要长度}}{\text{原文长度}} \] - **优势**：直接反映摘要是否**简洁、无冗余**。  ### 5. ROUGE-1、ROUGE-2 - **定义**：分别基于**Unigram（单词）**与**Bigram（双词）**的重叠度。 - **作用**：从**词汇层面**补充衡量信息召回率，与 ROUGE-L 共同构成完整 ROUGE 体系。  ---  ## 小结（可直接写论文） ROUGE 系列衡量**表面词汇与结构重叠**，BERTScore 与 BARTScore 从**语义与生成质量**层面更细粒度地评估摘要质量，压缩比则用于控制**简洁性**。这套指标可全面评价文本摘要的**信息保留、流畅性与简洁性**。

# 一、翻译评估核心维度（所有方法都围绕这4点）
1. **准确性 (Accuracy/Faithfulness)**
   不增、不减、不改原意，无幻觉。
2. **流畅度 (Fluency)**
   语法正确、自然、像母语者写的。
3. **完整性 (Completeness)**
   源句所有信息都覆盖。
4. **风格/术语一致性 (Style & Terminology)**
   正式/口语、专业术语统一。

# 二、自动评估指标（最常用、可代码实现）
## 1. 传统经典指标
- **BLEU**
  机器翻译最经典，侧重**n-gram 精确匹配**，适合**高资源语言对**（如英↔中）。
- **METEOR**
  考虑同义词、词根，比 BLEU 更合理。
- **TER (Translation Edit Rate)**
  编辑距离，改多少字能变参考译文。
- **CHRF、CHRF++**
  对**中↔英这种字符级语言**非常友好，比 BLEU 更靠谱。

## 2. 深度学习时代（现在主流）
- **COMET**
  基于预训练模型的**语义匹配**，**最接近人类判断**，强推。
- **BERTScore**
  用 BERT 做上下文嵌入相似度，比 BLEU 稳定很多。
- **XMOVER**
  跨语言句子嵌入相似度，简单好用。

> 工程推荐组合：
> **BLEU + CHRF++ + BERTScore + COMET**
> 足够发论文/写报告。

# 三、大模型时代：LLM-as-Judge 评估（最强）
直接用更强 LLM（GPT-4、Claude、LLama 3 等）打分，**效果远超传统指标**。

## 可直接用的评估 Prompt
```
你是专业翻译评估员，请从三个维度对译文打分（1–5分）：
1. 准确性：是否忠实原文，无增删改、无幻觉
2. 流畅度：是否通顺自然、符合目标语习惯
3. 完整性：是否完整覆盖原文所有信息

原文：{source}
参考译文（可选）：{reference}
模型译文：{hypo}

输出格式：
准确性：/5
流畅度：/5
完整性：/5
总分：/15
评语：
错误点：
```

优点：
- 能理解**语义、逻辑、语气、歧义**
- 支持**任意语言对**
- 可解释、可定位错误

# 四、人工评估（最权威，用于最终验收）
标准维度：
1. ** adequacy 充分性**（是否传达原意）
2. ** fluency 流畅度**
3. ** terminology 术语正确性**
4. ** style 风格恰当性**
打分：1~5 分制即可。

- 要**快、可复现、可对比** → 用 **BLEU + CHRF++ + BERTScore**
