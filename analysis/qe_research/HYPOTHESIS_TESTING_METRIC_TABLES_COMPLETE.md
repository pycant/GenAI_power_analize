# GPU能耗假设检验分析完成报告

**完成时间**: 2026-03-08 14:23:28

## 任务概述

基于 `analysis/qe_research/results/metric_tables/01_avg_gpu_energy.csv` 中的数据，创建了一个全面的GPU能耗假设检验分析报告。

## 研究问题

1. **RQ1**: 不同任务类型的GPU能耗是否存在显著差异？
2. **RQ2**: 不同模型的GPU能耗是否存在显著差异？
3. **RQ3**: 在同一任务下，不同模型的GPU能耗是否存在显著差异？

## 关键发现

### RQ1: 任务间差异 ✅
- **检验方法**: Kruskal-Wallis H检验
- **结果**: H = 39.0522, p < 0.0001
- **结论**: 不同任务类型的GPU能耗存在显著差异
- **能耗范围**: summary (339.04 J) 到 code (1790.55 J)，差异5.28倍
- **显著差异对**: 发现8对任务间存在显著差异（经Bonferroni校正）

### RQ2: 模型间差异 ✅
- **检验方法**: Kruskal-Wallis H检验
- **结果**: H = 42.9883, p < 0.0001
- **结论**: 不同模型的GPU能耗存在显著差异
- **能耗范围**: google--gemma-2b-it:4bit (225.27 J) 到 qwen--qwen2.5-7b-instruct:8bit (6271.10 J)，差异27.84倍

### RQ3: 任务内模型变异性 ✅
- **分析方法**: 描述性统计（变异系数CV和相对范围）
- **数据限制**: 每个任务-模型组合仅有1个平均值，无法进行传统假设检验
- **关键发现**:
  - 变异最大任务: creative (CV=116.02%, 相对范围=437.72%)
  - 变异最小任务: translation (CV=43.19%, 相对范围=151.64%)
  - 8个任务的CV均超过30%，表明模型选择对能耗影响显著

## 方法论改进

### 问题识别
用户正确指出原始RQ3分析存在问题：
- 数据为每个任务-模型组合的单一平均值（非重复测量）
- 使用Kruskal-Wallis检验单个数据点在统计上无效

### 解决方案
- 将RQ3从推断性假设检验改为描述性统计分析
- 使用变异系数(CV)和相对范围量化模型间差异
- 在报告中明确说明数据限制和方法选择理由

## 统计方法

### 主检验
- **Kruskal-Wallis H检验**: 非参数多组比较
  - 不要求正态分布
  - 对异常值稳健
  - 适用于≥3组比较

### 事后检验
- **Mann-Whitney U检验**: 两两比较
- **Bonferroni校正**: 控制家族错误率
- **显著性水平**: α = 0.05 / n_comparisons

### 描述性统计
- **变异系数(CV)**: 标准差/均值 × 100%
- **相对范围**: (最大值-最小值)/均值 × 100%

## 实践建议

### 模型选择策略
1. **能耗优先**: 选择小参数量、高效量化模型（如gemma-2b-it:4bit）
2. **性能优先**: 在能耗可接受范围内选择性能最优模型
3. **平衡策略**: 根据任务类型选择该任务下能耗-性能平衡最优的模型

### 任务优化建议
1. **高能耗任务** (code, creative): 考虑任务分解、批处理等优化策略
2. **低能耗任务** (summary, qa): 可以使用更大模型提升质量
3. **混合任务**: 根据任务类型动态选择模型

### 系统部署建议
1. **负载均衡**: 根据任务能耗特征分配计算资源
2. **模型缓存**: 对高频任务使用专用优化模型
3. **能耗监控**: 建立实时能耗监控和预警机制

## 研究局限性
