### 新的学术配色方案

已将原始数据分析器的颜色方案从默认的Viridis更新为专业的学术配色：

```python
academic_colors = [
    '#0173B2',  # 蓝色 - 主色调
    '#DE8F05',  # 橙色 - 对比色
    '#029E73',  # 绿色 - 辅助色
    '#CC78BC',  # 紫色 - 强调色
    '#CA9161',  # 棕色
    '#949494',  # 灰色
    '#ECE133',  # 黄色
    '#56B4E9'   # 浅蓝色

```

### 配色特点

1. **高对比度**: 颜色之间对比明显，易于区分不同数据系列
2. **色盲友好**: 考虑了色盲人群的视觉需求
3. **学术标准**: 符合学术出版物的配色规范
4. **打印友好**: 黑白打印时仍能保持良好的区分度

### 技术实现

```python
# 在初始化时设置
self.academic_colors = ['#0173B2', '#DE8F05', '#029E73', '#CC78BC',
                       '#CA9161', '#949494', '#ECE133', '#56B4E9']
sns.set_palette(self.academic_colors)

# 在绘图时使用
# 方法1: 直接使用
plt.plot(x, y, color=self.academic_colors[0])

# 方法2: 循环使用
for i, model in enumerate(models):
    color = self.academic_colors[i % len(self.academic_colors)]
    plt.scatter(x, y, color=color)

# 方法3: 指定多个颜色
plt.bar(x, y, color=self.academic_colors[:len(x)])
```

### 对比效果

#### 更新前 (Viridis)
- 颜色: 黄绿色渐变
- 对比度: 中等
- 适用场景: 热力图、连续数据

#### 更新后 (学术配色)
- 颜色: 8种离散色
- 对比度: 高
- 适用场景: 分类数据、多系列对比

### 优势

1. **更清晰的视觉区分**: 不同模型/类别更容易识别
2. **专业外观**: 符合学术论文和报告的标准
3. **通用性强**: 适用于各种图表类型
4. **可访问性好**: 考虑了色盲和打印需求

### 自定义配色

如需使用其他配色方案，可以修改 `_setup_plotting_style()` 方法：

```python
# 示例: 使用其他配色

    '#ff7f0e',  # 橙色
    '#2ca02c',  # 绿色

    '#8c564b',  # 棕色
    '#e377c2',  # 粉色

```
