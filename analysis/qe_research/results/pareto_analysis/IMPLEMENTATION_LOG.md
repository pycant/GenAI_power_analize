### 步骤1：定量指标计算器开发

**文件**：`analysis/qe_research/scripts/pareto_metrics_calculator.py`

**实现功能**：
1. 超体积（Hypervolume）计算
   - 2D超体积：质量-能耗、质量-速度
   - 参考点设置：最劣值
   
2. 间距指标（Spacing）计算
   - 评估前沿分布均匀性
   - 归一化距离计算
   
3. 最大扩散度（Maximum Spread）计算
   - 各维度范围
   - 归一化扩散度
   
4. 边际效益分析
   - ΔQ/ΔE计算
   - 边际效益排名
   
5. 拐点识别（Knee Point Detection）
   - 最大距离法
   - 边际效益法

## 🎓 技术细节

### 实现的算法

1. **超体积计算**
   - 2D超体积：矩形面积累加法
   - 参考点：最劣值（能耗最大值，质量最小值）

2. **间距指标计算**
   - 归一化欧氏距离
   - 最近邻距离标准差

3. **拐点识别**
   - 最大距离法：点到理想-反理想连线的最大距离
   - 边际效益法：边际效益下降最快的点

4. **扰动分析**
   - 高斯噪声：±5%
   - Jaccard相似度：集合交集/并集

5. **权重敏感性**
   - 均匀采样：±10%权重变化
   - 频率统计：最优模型出现频率

6. **交叉验证**
   - K折验证：5折
   - 一致性计算：模型出现频率
