## 1. 熵权法权重计算

### 1.1 方法说明

熵权法是一种客观赋权方法，通过计算各指标的信息熵来确定权重：

- **信息熵**：衡量数据的离散程度，熵值越小，信息量越大
- **多样性系数**：1 - 信息熵，反映指标的区分能力
- **权重**：多样性系数归一化后的结果

### 1.2 计算结果

| 评分维度 | 信息熵 | 多样性系数 | 权重 | 权重(%) |
|---------|--------|-----------|------|--------|
| 正确性 | 0.8945 | 0.1055 | 0.1924 | 19.24% |
| 完整性 | 0.8985 | 0.1015 | 0.1851 | 18.51% |
| 严谨性 | 0.9077 | 0.0923 | 0.1683 | 16.83% |
| 清晰度 | 0.8485 | 0.1515 | 0.2764 | 27.64% |
| 效率 | 0.9025 | 0.0975 | 0.1778 | 17.78% |

**关键发现**：
- 清晰度权重最高（27.64%），说明各模型在表达清晰度上差异最大
- 正确性权重次之（19.24%），反映推理准确性的重要性
- 各维度权重相对均衡，避免了单一维度主导的问题

## 6. 方法论说明

### 6.1 熵权法公式

```
1. 数据标准化：x'ij = (xij - min(xj)) / (max(xj) - min(xj))
2. 计算概率：pij = x'ij / Σx'ij
3. 信息熵：Ej = -1/ln(n) * Σ(pij * ln(pij))
4. 多样性：Dj = 1 - Ej
5. 权重：wj = Dj / ΣDj
```

### 6.2 帕累托最优定义

一个解被称为帕累托最优，当且仅当不存在其他解在所有目标上都不差于它，且至少在一个目标上优于它。

- **2D前沿**：在两个维度上不被支配的点
- **3D前沿**：在质量、速度、能耗三个维度上不被支配的点

### 6.3 综合评分计算

```
综合评分 = 质量(归一化) × 0.4 + 速度(归一化) × 0.3 + 能效(归一化) × 0.3
其中：能效 = 1 - 能耗(归一化)
```
