# 非帕累托点

# 网格

### 设计理念

- **蓝色系**: 表示非前沿点，冷静、专业
- **橙红色**: 表示前沿点，醒目、重要
- **渐变**: 表示性能梯度，直观易懂
- **浅色背景**: 柔和不刺眼，适合长时间查看

## 📝 代码示例

### 基本使用

```python
from pareto_core.shared_functions import plot_pareto_2d, identify_pareto_frontier_2d

# 准备数据
df = pd.DataFrame({
    'model': ['model_a', 'model_b', 'model_c'],
    'quality': [0.8, 0.9, 0.7],
    'speed': [50, 40, 60]
})

# 识别帕累托前沿
pareto_mask = identify_pareto_frontier_2d(
    df,
    x_col='speed',
    y_col='quality',
    x_minimize=False,  # 速度越大越好
    y_minimize=False   # 质量越大越好
)

# 绘制增强版图表
plot_pareto_2d(
    df=df,
    pareto_mask=pareto_mask,
    x_col='speed',
    y_col='quality',
    title='质量-速度帕累托前沿分析',
    output_path='pareto_quality_speed.png',
    x_label='推理速度 (tokens/s)',
    y_label='综合质量得分',
    x_minimize=False,
    y_minimize=False
)
```

## 🔧 技术细节

### 距离计算

```python
# 归一化坐标
pareto_coords = np.column_stack([
    (pareto_df[x_col] - df[x_col].min()) / x_range,
    (pareto_df[y_col] - df[y_col].min()) / y_range
])

# 计算欧氏距离
distances = cdist(non_pareto_coords, pareto_coords).min(axis=1)
```

### 最优模型识别

```python
# 归一化并根据优化方向调整
x_norm = (pareto_df[x_col] - df[x_col].min()) / (df[x_col].max() - df[x_col].min())
if not x_minimize:
    x_norm = 1 - x_norm

# 计算到理想点的距离
distances_to_ideal = np.sqrt(x_norm**2 + y_norm**2)
best_idx = distances_to_ideal.idxmin()
```
