# plot_pareto_2d 函数优化方案

> 📅 提案时间: 2026-03-09
> 
> 🎯 目标: 提升帕累托前沿图的美观性和信息丰富度

## 当前实现分析

### 现有功能
- ✅ 基本散点图绘制
- ✅ 帕累托点与非帕累托点区分
- ✅ 模型名称标注
- ✅ 网格线和图例

### 存在的问题
1. **视觉单调**: 只有灰色和红色两种颜色，缺乏视觉层次
2. **信息密度低**: 没有展示模型的性能差异程度
3. **标注混乱**: 所有标签都显示，重叠严重
4. **缺少引导**: 没有帕累托前沿连线，不够直观
5. **缺少统计信息**: 没有显示关键统计数据
6. **交互性差**: 静态图表，无法获取更多信息

## 优化方案

### 方案 A: 渐进式增强（推荐）⭐

**特点**: 在保持兼容性的基础上，逐步增强视觉效果

#### A1. 视觉增强
```python
# 1. 使用渐变色映射表示性能
# - 根据综合得分或距离前沿的距离着色
# - 使用专业配色方案（如 viridis, plasma）

# 2. 差异化点的大小
# - 根据模型参数量或性能调整点的大小
# - 帕累托点使用更大的标记

# 3. 添加帕累托前沿连线
# - 用虚线或实线连接前沿点
# - 突出显示最优区域
```

**优点**:
- ✅ 向后兼容，不破坏现有功能
- ✅ 实现简单，风险低
- ✅ 视觉效果显著提升

**缺点**:
- ⚠️ 仍然是静态图表
- ⚠️ 信息密度提升有限

---

#### A2. 信息增强
```python
# 1. 智能标注
# - 只标注帕累托点和关键点
# - 使用避让算法防止重叠
# - 添加指向线连接标签和点

# 2. 添加统计信息框
# - 帕累托点数量
# - 前沿覆盖率
# - 最优模型信息

# 3. 添加参考线
# - 平均值线
# - 中位数线
# - 目标区域标注
```

**优点**:
- ✅ 信息更丰富
- ✅ 可读性更好
- ✅ 便于快速理解

**缺点**:
- ⚠️ 代码复杂度增加
- ⚠️ 需要额外的布局计算

---

### 方案 B: 多子图布局

**特点**: 在一张图中展示多个视角

#### B1. 2x2 子图布局
```
┌─────────────────┬─────────────────┐
│  主图：帕累托前沿  │  密度热力图       │
│  (散点图)        │  (2D histogram) │
├─────────────────┼─────────────────┤
│  X轴分布直方图    │  Y轴分布直方图    │
│  (histogram)    │  (histogram)    │
└─────────────────┴─────────────────┘
```

**优点**:
- ✅ 信息密度极高
- ✅ 展示数据分布特征
- ✅ 专业性强

**缺点**:
- ❌ 图表复杂，可能难以理解
- ❌ 实现复杂度高
- ❌ 文件大小增加

---

### 方案 C: 交互式可视化

**特点**: 使用 Plotly 创建交互式图表

#### C1. 交互功能
```python
# 1. 鼠标悬停显示详细信息
# - 模型名称
# - 精确数值
# - 排名信息

# 2. 点击高亮
# - 点击某个点高亮显示
# - 显示该模型在其他图表中的位置

# 3. 缩放和平移
# - 自由缩放查看细节
# - 平移浏览全局

# 4. 导出功能
# - 导出为 HTML（交互式）
# - 导出为 PNG（静态）
```

**优点**:
- ✅ 用户体验最佳
- ✅ 信息获取最便捷
- ✅ 现代化、专业

**缺点**:
- ❌ 需要额外依赖（plotly）
- ❌ HTML 文件不便于论文使用
- ❌ 实现和维护成本高

## 代码示例（第一阶段）

### 优化后的函数签名
```python
def plot_pareto_2d_enhanced(
    df, pareto_mask, x_col, y_col, title, output_path,
    x_label, y_label, x_minimize=True, y_minimize=True,
    # 新增参数
    color_by='distance',  # 'distance', 'quality', 'none'
    show_frontier_line=True,
    annotate_mode='pareto_only',  # 'all', 'pareto_only', 'top_n'
    size_by=None,  # None, 'params', 'quality'
    show_stats=True,
    color_map='viridis'
):
    """
    绘制增强版2D帕累托前沿图
    """
```

### 关键代码片段

#### 1. 渐变色映射
```python
# 计算到帕累托前沿的距离
distances = calculate_distance_to_frontier(df, pareto_mask, x_col, y_col)

# 创建颜色映射
if color_by == 'distance':
    colors = plt.cm.viridis(distances / distances.max())
elif color_by == 'quality':
    colors = plt.cm.plasma(df['quality'] / df['quality'].max())
else:
    colors = 'lightblue'
```

#### 2. 帕累托前沿连线
```python
# 对帕累托点排序并连线
pareto_sorted = pareto.sort_values(by=x_col)
ax.plot(pareto_sorted[x_col], pareto_sorted[y_col],
        'r--', alpha=0.5, linewidth=2, zorder=4,
        label='帕累托前沿')
```

#### 3. 智能标注（使用 adjustText）
```python
from adjustText import adjust_text

texts = []
# 只标注帕累托点
for _, row in pareto.iterrows():
    texts.append(ax.text(row[x_col], row[y_col], row['model'],
                        fontsize=9, fontweight='bold'))

# 自动调整避免重叠
adjust_text(texts, arrowprops=dict(arrowstyle='->', color='gray', lw=0.5))
```
