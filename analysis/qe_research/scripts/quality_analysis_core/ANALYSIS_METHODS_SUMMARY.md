# 质量数据分析方法总结

基于 `reference.md` 提取的分析方法和内容结构

## 一、报告结构框架

### 1. 数据概览
- 数据维度统计（模型数量、任务类型、指标总数、数据点总数）
- 模型清单（参数规模、量化方式、来源、任务覆盖）

### 2. 各任务质量得分分布分析
- 数据文件信息
- 样本数统计
- 描述性统计（均值、标准差、最小值、最大值、中位数、变异系数）
- 关键发现（4-5个要点）
- 模型排名（按主要指标，Top 10-12）

### 3. 跨任务综合分析
- 综合得分排名（等权平均）
- 模型规模与质量关系
- 量化方式影响分析
- 不同来源对比（Ollama vs HuggingFace）

### 4. 指标间相关性分析
- 任务内指标相关性矩阵
- 跨任务核心指标相关性
- 核心发现总结

### 5. 异常值与特殊现象
- 异常值检测表格
- 特殊现象描述

### 6. 核心结论
- 任务难度排序
- 模型能力聚类
- 量化建议
- 任务适配建议

### 7. 下一步分析建议

## 二、关键分析方法

### 1. 描述性统计
- 均值、中位数、标准差
- 最小值、最大值、范围
- 四分位数（Q25, Q75）、IQR
- 偏度、峰度
- 变异系数（CV = std/mean）

### 2. 模型排名
- 按主要指标降序排列
- 显示Top 10-12模型
- 包含多个相关指标

### 3. 跨任务综合评分
- 归一化各任务主要指标
- 等权平均计算综合得分
- 识别优势任务和劣势任务

### 4. 模型规模分析
- 按参数规模分组（2B, 3B-4B, 7B-8B）
- 计算各组平均综合得分
- 分析规模与质量的相关性

### 5. 量化方式对比
- 同一模型不同量化版本对比
- 计算4-bit vs 8-bit的差值
- 分析量化对不同任务的影响

### 6. 相关性分析
- 任务内指标相关性矩阵
- 跨任务核心指标相关性
- 识别高相关指标对（r > 0.6）

### 7. 异常值检测
- IQR方法（1.5倍IQR）
- Z-score方法（|z| > 3）
- 识别极端值和特殊现象

### 8. 可视化
- 分布图（直方图 + KDE）
- 箱线图/散点图（模型对比）
- 相关性热力图
- 雷达图（综合能力对比）
- 跨任务热力图（模型×任务矩阵）
