# GPU能耗假设检验功能说明

## 功能概述

为原始数据分析脚本 `raw_data_analysis.py` 添加了完整的统计假设检验功能，用于科学地回答以下核心问题：

1. **不同任务类型的GPU能耗是否存在显著差异？**
   - 例如：code任务和creative任务的能耗是否有统计学意义上的差异？

2. **不同模型的GPU能耗是否存在显著差异？**
   - 例如：qwen模型和gemma模型的能耗是否有显著不同？

3. **任务类型和模型之间是否存在交互效应？**
   - 例如：某个模型在特定任务上的能耗表现是否特别突出？

## 为什么需要假设检验？

在实验数据分析中，我们经常会观察到不同组之间的差异，但这些差异可能是：
- **真实差异**：由于任务或模型本身的特性导致
- **随机波动**：由于测量误差、环境因素等随机因素导致

假设检验通过统计方法帮助我们判断观察到的差异是否具有统计学意义，而不仅仅是随机波动。

## 核心功能

### 1. 任务间差异检验

**检验流程**：
```
数据收集 → 描述性统计 → 正态性检验 → 方差齐性检验 
→ 主检验(ANOVA/Kruskal-Wallis) → 事后检验(两两比较)
```

**输出结果**：
- 描述性统计表（均值、标准差、中位数等）
- 正态性检验结果
- 主检验结果（p值、统计量）
- 事后比较结果（哪些任务对之间存在显著差异）
- 箱线图可视化

### 2. 模型间差异检验

**检验方法**：
- 使用Kruskal-Wallis H检验（非参数方法）
- 适用于多个模型的比较

**输出结果**：
- 描述性统计表
- 检验结果（p值、H统计量）
- 箱线图可视化

### 3. 交互效应分析

**分析内容**：
- 创建任务×模型的能耗矩阵
- 生成热力图展示交互模式
- 识别特殊的任务-模型组合

**输出结果**：
- 交互效应表（CSV）
- 热力图（PNG）

## 结果解读指南

### 如何看懂p值？

| p值 | 含义 | 符号 | 结论 |
|-----|------|------|------|
| < 0.001 | 极显著差异 | *** | 有极强证据表明存在差异 |
| < 0.01 | 非常显著差异 | ** | 有很强证据表明存在差异 |
| < 0.05 | 显著差异 | * | 有证据表明存在差异 |
| ≥ 0.05 | 无显著差异 | ns | 无足够证据表明存在差异 |

### 示例1：任务间检验结果

```
检验类型: Kruskal-Wallis H检验
H统计量: 25.34
p值: 0.0001
结论: 存在显著差异 ***
```

**解读**：
- p = 0.0001 < 0.05，拒绝零假设
- 结论：不同任务类型的GPU能耗存在极显著差异
- 下一步：查看事后比较，确定具体哪些任务对之间存在差异

### 示例2：事后比较结果

```
组1: code, 组2: creative, p值: 0.0023, 是否显著: 是
组1: code, 组2: qa, p值: 0.1234, 是否显著: 否
组1: creative, 组2: qa, p值: 0.0456, 是否显著: 是
```

**解读**：
- code和creative任务的能耗有显著差异（p=0.0023）
- code和qa任务的能耗无显著差异（p=0.1234）
- creative和qa任务的能耗有显著差异（p=0.0456）

### 示例3：箱线图解读

箱线图中的元素：
- **箱体**：表示数据的中间50%（第25到第75百分位）
- **中线**：表示中位数
- **须**：表示数据的范围（不包括离群值）
- **点**：表示离群值

## 统计方法说明

### 1. Shapiro-Wilk检验（正态性）
- **目的**：判断数据是否服从正态分布
- **零假设**：数据服从正态分布
- **判断**：p > 0.05 → 数据正态

### 2. Levene检验（方差齐性）
- **目的**：判断各组方差是否相等
- **零假设**：各组方差相等
- **判断**：p > 0.05 → 方差齐性

### 3. ANOVA（单因素方差分析）
- **适用**：数据正态 + 方差齐性
- **零假设**：各组均值相等
- **判断**：p < 0.05 → 存在显著差异

### 4. Kruskal-Wallis H检验
- **适用**：数据不正态或方差不齐
- **零假设**：各组分布相同
- **判断**：p < 0.05 → 存在显著差异

### 5. Mann-Whitney U检验（事后比较）
- **目的**：两组间的非参数比较
- **Bonferroni校正**：控制多重比较的错误率

## 注意事项

### ⚠️ 样本量要求
- 每组至少需要3个样本
- 建议每组至少10个样本以获得可靠结果

### ⚠️ 统计显著 ≠ 实际重要
- p < 0.05只表示统计显著
- 还需要关注实际差异的大小（均值差）
- 小的差异可能统计显著但实际不重要

### ⚠️ 多重比较校正
- 进行多次比较时必须校正显著性水平
- 本实现使用Bonferroni校正（较保守）

### ⚠️ 数据质量
- 异常值可能影响结果
- 箱线图可以帮助识别异常值
- 非参数方法对异常值更稳健

## 常见问题

### Q1: 提示"任务类型不足，无法进行假设检验"
**原因**：数据中只有一种任务类型
**解决**：确保数据包含至少2种不同的任务类型

### Q2: 提示"样本量不足"
**原因**：某些任务或模型的样本数太少
**解决**：收集更多实验数据，每组至少3个样本

### Q3: 所有检验都显示"不显著"
**可能原因**：
- 样本量太小，检验效力不足
- 各组确实没有显著差异
- 数据变异性太大

### Q4: 图表中文显示乱码
**解决**：脚本会自动处理，使用英文标签作为备选
