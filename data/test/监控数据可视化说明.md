# 监控数据可视化说明

## 概述

实验运行器现在会自动保存详细的硬件监控数据，包括CPU、内存、GPU使用率、显存、功耗、温度等实时指标。这些数据可以通过可视化脚本生成图表，帮助深入分析模型运行时的硬件行为。

## 数据结构

### JSON文件格式

每个实验结果JSON文件包含以下关键字段：

```json
{
  "model": "模型名称",
  "task_type": "任务类型",
  "system_metrics_summary": {
    "cpu_percent_avg": "平均CPU使用率",
    "gpu_util_avg": "平均GPU使用率",
    "gpu_energy_j": "GPU总能耗（焦耳）",
    ...
  },
  "system_metrics_full": {
    "timestamps": [时间戳数组],
    "cpu_percent": [CPU使用率数组],
    "gpu_util": [GPU使用率数组],
    "gpu_mem_mb": [GPU显存数组],
    "gpu_power_w": [GPU功耗数组],
    "gpu_temp_c": [GPU温度数组],
    ...
  }
}
```

### 监控指标说明

#### CPU指标
- `cpu_percent`: 系统整体CPU使用率（%）
- `cpu_proc_percent`: Ollama进程CPU使用率（%）
- `cpu_power_w_approx`: 估算的CPU功耗（W）
- `cpu_energy_j_approx`: 估算的CPU总能耗（J）

#### 内存指标
- `mem_used_mb`: 系统内存使用量（MB）

#### GPU指标
- `gpu_util`: GPU核心使用率（%）
- `gpu_mem_mb`: GPU显存使用量（MB）
- `gpu_power_w`: GPU实时功耗（W）
- `gpu_temp_c`: GPU温度（°C）
- `gpu_energy_j`: GPU总能耗（J）

#### 磁盘I/O
- `disk_read_bytes`: 磁盘读取字节数
- `disk_write_bytes`: 磁盘写入字节数

## 使用方法

### 1. 运行实验（自动保存监控数据）

```bash
conda activate bartscore
python experiments/experiment_runner.py --config data/test/test_cases.json --output-dir data/test
```

实验结果会保存为 `experiment_results_YYYYMMDD_HHMMSS.json`，包含完整的监控数据。

### 2. 可视化监控数据

#### 查看汇总信息

```bash
python scripts/visualize_monitoring_data.py data/test/experiment_results_20260228_194736.json --summary-only
```

输出示例：
```
[1] Ollama:qwen3:4b - summary
  CPU: 平均 39.6%, 峰值 85.1%
  GPU使用率: 平均 57.3%, 峰值 94.0%
  GPU能耗: 333.21 J
  监控时长: 7.17 秒
```

#### 生成详细图表（每个实验单独）

```bash
python scripts/visualize_monitoring_data.py data/test/experiment_results_20260228_194736.json --output data/test/figures
```

为每个实验生成6个子图：
1. CPU使用率（系统 + Ollama进程）
2. 内存使用
3. GPU使用率
4. GPU显存
5. GPU功耗（含平均线）
6. GPU温度（含警戒线）

#### 生成对比图表（多实验横向对比）

```bash
python scripts/visualize_monitoring_data.py data/test/experiment_results_20260228_194736.json --output data/test/figures --comparison
```

生成4个对比图：
1. CPU使用率对比
2. GPU使用率对比
3. GPU显存对比
4. GPU功耗对比

#### 只可视化特定实验

```bash
python scripts/visualize_monitoring_data.py data/test/experiment_results_20260228_194736.json --index 0 --output data/test/figures
```

### 3. 查看生成的图表

图表保存在指定的输出目录中：
- 单个实验图表：`monitoring_{模型名}_{任务类型}.png`
- 对比图表：`monitoring_comparison.png`

## 实验结果分析

### 本次实验关键发现

基于 `experiment_results_20260228_194736.json` 的分析：

#### 1. GPU使用率分析

| 模型 | 任务 | 平均GPU使用率 | 峰值GPU使用率 | 显存峰值 |
|------|------|---------------|---------------|----------|
| qwen3:4b | summary | 57.3% | 94.0% | 5.9 GB |
| gemma3:4b | code | 48.7% | 92.0% | 6.6 GB |
| deepseek-r1:8b | qa | 90.5% | 100.0% | 8.0 GB |
| qwen3:8b | creative | 89.8% | 100.0% | 8.0 GB |

**观察**：
- 8B模型（deepseek-r1、qwen3）的GPU使用率明显高于4B模型
- deepseek-r1和qwen3:8b都达到了100%的峰值使用率
- 显存使用与模型大小成正比

#### 2. 能耗分析

| 模型 | 任务 | 平均功耗 | 总能耗 | 耗时 | 能效比 |
|------|------|----------|--------|------|--------|
| qwen3:4b | summary | 45.9 W | 333.21 J | 6.70s | 49.7 J/s |
| gemma3:4b | code | 40.2 W | 428.40 J | 10.05s | 42.6 J/s |
| deepseek-r1:8b | qa | 38.1 W | 1850.83 J | 48.06s | 38.5 J/s |
| qwen3:8b | creative | 35.8 W | 1535.45 J | 42.46s | 36.2 J/s |

**观察**：
- 虽然8B模型的GPU使用率更高，但平均功耗反而更低
- 这可能是因为8B模型运行时间更长，GPU进入了更稳定的工作状态
- qwen3:4b的瞬时功耗最高（45.9W），但总能耗最低（运行时间短）

#### 3. 温度管理

所有模型的GPU温度都控制在66-68°C之间，远低于80°C的警戒温度，说明散热良好。

#### 4. CPU使用情况

| 模型 | 平均CPU | 峰值CPU | 内存峰值 |
|------|---------|---------|----------|
| qwen3:4b | 39.6% | 85.1% | 12.5 GB |
| gemma3:4b | 36.4% | 76.7% | 13.2 GB |
| deepseek-r1:8b | 41.0% | 84.8% | 13.1 GB |
| qwen3:8b | 41.2% | 89.4% | 13.4 GB |

**观察**：
- CPU使用率在各模型间差异不大
- 内存使用量相对稳定，都在12-13.5 GB范围内

## 高级用法

### 自定义分析

可以直接读取JSON文件进行自定义分析：

```python
import json
import matplotlib.pyplot as plt

# 加载数据
with open('data/test/experiment_results_20260228_194736.json', 'r') as f:
    experiments = json.load(f)

# 提取第一个实验的GPU功耗数据
exp = experiments[0]
metrics = exp['system_metrics_full']
timestamps = metrics['timestamps']
gpu_power = metrics['gpu_power_w']

# 计算相对时间
start_time = timestamps[0]
relative_times = [(t - start_time) for t in timestamps]

# 绘制自定义图表
plt.plot(relative_times, gpu_power)
plt.xlabel('Time (s)')
plt.ylabel('GPU Power (W)')
plt.title('Custom GPU Power Analysis')
plt.show()
```

### 导出为CSV

```python
import pandas as pd

# 转换为DataFrame
df = pd.DataFrame({
    'time': relative_times,
    'gpu_power': gpu_power,
    'gpu_util': metrics['gpu_util'],
    'gpu_temp': metrics['gpu_temp_c']
})

# 保存为CSV
df.to_csv('monitoring_data.csv', index=False)
```

## 故障排查

### 问题：没有详细监控数据

**原因**：ResourceMonitor不可用或监控失败

**解决**：
1. 检查是否安装了 `pynvml` 包：`pip install pynvml`
2. 确认NVIDIA驱动正常工作：`nvidia-smi`
3. 查看实验输出中的警告信息

### 问题：图表中文乱码

**解决**：
1. 确保系统安装了中文字体（如Microsoft YaHei）
2. 脚本会自动检测并使用可用的中文字体
3. 如果仍有问题，可以手动修改 `visualize_monitoring_data.py` 中的字体设置

### 问题：可视化脚本报错

**解决**：
1. 确保安装了matplotlib：`pip install matplotlib`
2. 检查JSON文件格式是否正确
3. 使用 `--summary-only` 参数先查看数据是否完整

## 最佳实践

1. **实验命名**：使用描述性的配置文件名，便于后续识别
2. **定期备份**：重要实验结果及时备份到其他目录
3. **对比分析**：使用 `--comparison` 参数生成对比图表，便于横向比较
4. **长时间实验**：对于长时间运行的实验，监控数据会更详细和准确
5. **多次运行**：同一配置运行多次，取平均值以获得更稳定的结果
