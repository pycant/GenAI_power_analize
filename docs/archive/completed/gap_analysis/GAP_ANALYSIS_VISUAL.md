## 指标依赖关系图

```
基础测量指标
├─ P_idle (空闲功耗) ────────┐
├─ P_avg (平均功耗)          │
├─ E_total (总能耗)          │
├─ T_total (总时间)          │
├─ output_tokens (输出token) │
└─ toks_per_s (吞吐量)       │
                             │
                             ▼
衍生指标 (依赖基础指标)
├─ P_inc = P_avg - P_idle ◄──┘
├─ E_token = E_total / output_tokens
├─ PPW = toks_per_s / P_avg
└─ TPJ = output_tokens / E_total
                             │
                             ▼
归一化指标 (依赖原始指标)
├─ norm_quality
├─ norm_energy
├─ norm_latency
├─ norm_power 🆕
└─ norm_throughput
                             │
                             ▼
复合指标 (依赖归一化指标)
├─ efficiency_score
├─ qe_ratio
├─ fair_quality_score
└─ Score_final 🆕
```
