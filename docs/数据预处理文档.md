## 概述

### 目标

本文档详细说明了 GenAI 模型质效比评估项目中的数据预处理流程，包括：
- 原始实验数据的提取与清洗
- 多维度质量指标的计算
- 标准化数据格式的转换
- 高性能数据管道的构建

### 核心特性

- **自动化**: 一键运行完整预处理流程
- **标准化**: 统一的数据格式和命名规范
- **高性能**: Parquet 格式，读取速度提升 5-10 倍
- **可追溯**: 完整的数据血缘和元数据管理
- **可扩展**: 模块化设计，易于添加新任务类型

### 数据流说明

1. **原始数据源**: 实验运行产生的 JSON 文件，包含完整对话和性能指标
2. **数据提取层**: 从 JSON 提取结构化数据，保存为 CSV 格式
3. **中间数据**: 便于人工查看和初步分析的 CSV 文件
4. **质量评估层**: 计算多维度质量指标
5. **数据管道层**: ETL 转换，生成标准化高性能数据格式
6. **标准化数据**: Parquet 格式，支持快速查询和分析
7. **分析层**: 基于标准化数据进行统计分析和可视化

## 预处理流程

### 阶段 1: 数据提取

#### 脚本: `extract_responses.py`

**功能**:
- 遍历所有模型目录
- 从 `*_raw.json` 提取完整回答文本
- 从 `*_summary.json` 提取性能和资源指标
- 自动处理特殊字符（换行符、引号、逗号）
- 生成统计摘要

**运行方式**:

```bash
conda activate bartscore
set PYTHONUTF8=1
python data/analize/scripts/extract_responses.py
```

**输出文件**:

1. **responses_raw.csv** (674 KB)
   - 包含所有模型的完整回答
   - 字段: experiment_id, model, task_type, prompt, response, response_length, token_count, throughput_tps, latency_s, gpu_energy_j, gpu_power_avg_w, bartscore, timestamp

2. **responses_summary.csv** (20 KB)
   - 按模型和任务类型汇总的统计数据
   - 字段: model, task_type, sample_count, response_length_mean/std/min/max, token_count_mean/std, throughput_tps_mean/std, latency_s_mean/std, gpu_energy_j_mean/std

**数据示例**:

```csv
experiment_id,model,task_type,prompt,response,response_length,token_count,throughput_tps,latency_s,gpu_energy_j
code_custom_r1,qwen_8b_ol_q4km,code,"编写函数","def fib(n):...",245,158,45.2,3.5,1234.5
```

#### 脚本: `create_comparison_matrix.py`

**功能**:
- 为每个任务类型创建独立的对比表
- 行 = 模型，列 = 题号，单元格 = 回答/指标
- 便于横向对比不同模型在同一问题上的表现

**输出结构**:

### ETL 流程

#### 1. Extract (提取)

从多个数据源加载原始数据：

```python
def _load_raw_data(self) -> pd.DataFrame:
    """加载原始数据"""
    dfs = []
    
    # 1. 加载实验 JSON 数据
    summary_loader = SummaryJsonLoader(base_path=self.base_path.parent)
    df_summary = summary_loader.load_all_summary_data()
    dfs.append(df_summary)
    
    # 2. 加载 responses_raw.csv
    df = pd.read_csv(self.raw_path / 'responses_raw.csv')
    dfs.append(df)
    
    # 3. 加载 comparison_matrices
    for task_dir in (self.raw_path / 'comparison_matrices').iterdir():
        for csv_file in task_dir.glob('*.csv'):
            df = pd.read_csv(csv_file)
            dfs.append(df)
    
    # 4. 加载质量评估结果
    for task_dir in self.results_path.iterdir():
        for csv_file in task_dir.glob('quality_summary_*.csv'):
            df = pd.read_csv(csv_file)
            dfs.append(df)
    
    return pd.concat(dfs, ignore_index=True)
```

#### 2. Transform (转换)

清洗、标准化和计算派生指标：

```python
def _clean_and_standardize(self, df: pd.DataFrame) -> pd.DataFrame:
    """清洗和标准化数据"""
    # 1. 标准化列名
    df.columns = df.columns.str.lower().str.replace(' ', '_')
    
    # 2. 标准化模型名称
    df['model_name'] = df['model_name'].str.lower().str.strip()
    
    # 3. 标准化任务类型
    df['task_type'] = df['task_type'].str.lower().str.strip()
    
    # 4. 转换数据类型
    df = self._convert_dtypes(df)
    
    # 5. 处理缺失值
    df = self._handle_missing_values(df)
    
    # 6. 去重
    df = df.drop_duplicates(subset=PRIMARY_KEYS, keep='last')
    
    return df
```

```python
def _compute_derived_metrics(self, df: pd.DataFrame) -> pd.DataFrame:
    """计算派生指标"""
    # 按任务分组计算归一化指标
    for task in df['task_type'].unique():
        mask = df['task_type'] == task
        
        # 归一化效率指标
        df.loc[mask, 'norm_toks_per_s'] = self._normalize(df.loc[mask, 'toks_per_s'])
        df.loc[mask, 'norm_latency_s'] = self._normalize(df.loc[mask, 'latency_s'])
        df.loc[mask, 'norm_gpu_energy_j'] = self._normalize(df.loc[mask, 'gpu_energy_j'])
        
        # 归一化质量指标
        quality_cols = self.schema.get_quality_columns(task)
        for col in quality_cols:
            if col in df.columns:
                df.loc[mask, f'norm_{col}'] = self._normalize(df.loc[mask, col])
    
    # 计算效率得分
    weights = PipelineConfig.EFFICIENCY_WEIGHTS
    df['efficiency_score'] = (
        weights['throughput'] * df['norm_toks_per_s'] +
        weights['latency'] * (1 - df['norm_latency_s']) +
        weights['energy'] * (1 - df['norm_gpu_energy_j'])
    )
    
    # 计算质效比
    df['qe_ratio'] = (df['norm_quality'] + 0.01) / (1.01 - df['efficiency_score'])
    
    return df
```

#### 3. Load (加载)

保存为高性能 Parquet 格式：

```python
def _save_master_data(self, df: pd.DataFrame):
    """保存主数据"""
    output_file = self.processed_path / 'master_data.parquet'
    
    # 优化存储：使用 category 类型
    for col in ['model_name', 'task_type']:
        if col in df.columns:
            df[col] = df[col].astype('category')
    
    # 保存为 Parquet 格式
    df.to_parquet(
        output_file,
        engine='pyarrow',
        compression='snappy',
        index=False
    )
```

### 基础评估器接口

```python
from abc import ABC, abstractmethod
from typing import Dict, Any

class BaseEvaluator(ABC):
    """质量评估器基类"""
    
    @abstractmethod
    def evaluate(self, generated: str, reference: str = None, 
                 context: Dict[str, Any] = None) -> Dict[str, float]:
        """
        评估生成文本质量，返回多维度指标
        
        Args:
            generated: 生成的文本
            reference: 参考答案（可选）
            context: 额外上下文信息
        
        Returns:
            Dict[str, float]: 多维度指标字典
        """
        pass
    
    def get_metric_categories(self) -> Dict[str, List[str]]:
        """返回指标分类"""
        return {}
    
    def get_metric_directions(self) -> Dict[str, bool]:
        """返回指标方向（True=越大越好，False=越小越好）"""
        return {}
```

### 代码生成评估示例

```python
class CodeEvaluator(BaseEvaluator):
    """代码生成质量评估器"""
    
    def evaluate(self, generated: str, reference: str = None, 
                 context: Dict[str, Any] = None) -> Dict[str, float]:
        scores = {}
        
        # 1. 编译检查
        try:
            compile(generated, '<string>', 'exec')
            scores['compilation_rate'] = 1.0
        except:
            scores['compilation_rate'] = 0.0
            return scores
        
        # 2. 代码长度
        scores['code_length'] = len(generated.split('\n'))
        
        # 3. 圈复杂度
        try:
            from radon.complexity import cc_visit
            complexity = cc_visit(generated)
            scores['cyclomatic_complexity'] = sum(c.complexity for c in complexity)
        except:
            scores['cyclomatic_complexity'] = 0
        
        # 4. 测试用例通过率（如果有）
        if context and 'test_cases' in context:
            passed = self._run_test_cases(generated, context['test_cases'])
            scores['test_pass_rate'] = passed / len(context['test_cases'])
        
        return scores
```

### 创意写作评估示例

```python
class CreativeEvaluator(BaseEvaluator):
    """创意写作质量评估器"""
    
    def evaluate(self, generated: str, reference: str = None, 
                 context: Dict[str, Any] = None) -> Dict[str, float]:
        scores = {}
        
        # 1. Distinct-N
        tokens = generated.split()
        
        # Distinct-1
        unigrams = tokens
        scores['distinct_1'] = len(set(unigrams)) / len(unigrams) if unigrams else 0
        
        # Distinct-2
        bigrams = [' '.join(tokens[i:i+2]) for i in range(len(tokens)-1)]
        scores['distinct_2'] = len(set(bigrams)) / len(bigrams) if bigrams else 0
        
        # 2. 独特词汇比例
        scores['unique_token_ratio'] = len(set(tokens)) / len(tokens) if tokens else 0
        
        # 3. 修辞手法检测
        rhetorical_devices = self._detect_rhetorical_devices(generated)
        scores.update(rhetorical_devices)
        
        # 4. 困惑度（可选）
        if hasattr(self, 'perplexity_model'):
            scores['perplexity'] = self._compute_perplexity(generated)
        
        return scores
```

### 摘要生成评估示例

```python
class SummaryEvaluator(BaseEvaluator):
    """摘要生成质量评估器"""
    
    def evaluate(self, generated: str, reference: str = None, 
                 context: Dict[str, Any] = None) -> Dict[str, float]:
        scores = {}
        
        if not reference:
            return scores
        
        # 1. ROUGE 分数
        try:
            from rouge import Rouge
            rouge = Rouge()
            rouge_scores = rouge.get_scores(generated, reference)[0]
            scores['rouge_1_f1'] = rouge_scores['rouge-1']['f']
            scores['rouge_2_f1'] = rouge_scores['rouge-2']['f']
            scores['rouge_l_f1'] = rouge_scores['rouge-l']['f']
        except:
            pass
        
        # 2. BERTScore
        try:
            from bert_score import score
            P, R, F1 = score([generated], [reference], lang='zh', verbose=False)
            scores['bertscore_f1'] = F1.item()
        except:
            pass
        
        # 3. BARTScore（如果有源文本）
        if context and 'source_text' in context:
            try:
                from bart_score import BARTScorer
                bart_scorer = BARTScorer(device='cuda')
                scores['bartscore_avg'] = bart_scorer.score(
                    [context['source_text']], [generated]
                )[0]
            except:
                pass
        
        # 4. 压缩比
        if context and 'source_text' in context:
            scores['compression_ratio'] = len(generated) / len(context['source_text'])
        
        return scores
```

### 评估流程

1. **加载原始数据**: 从 `responses_raw.csv` 读取模型回答
2. **调用评估器**: 根据任务类型选择对应的评估器
3. **计算指标**: 评估器返回多维度质量指标
4. **保存结果**: 保存详细评分和汇总统计

```python
# 评估流程示例
def evaluate_all_models(task_type: str):
    # 1. 加载数据
    df = pd.read_csv('data/analize/pre_data/responses_raw.csv')
    df_task = df[df['task_type'] == task_type]
    
    # 2. 选择评估器
    evaluator = get_evaluator(task_type)
    
    # 3. 评估每个回答
    results = []
    for idx, row in df_task.iterrows():
        scores = evaluator.evaluate(
            generated=row['response'],
            reference=row.get('reference'),
            context={'prompt': row['prompt']}
        )
        scores['model'] = row['model']
        scores['question_id'] = row['experiment_id']
        results.append(scores)
    
    # 4. 保存结果
    df_scores = pd.DataFrame(results)
    df_scores.to_csv(f'results/{task_type}_quality/quality_scores_{task_type}.csv')
    
    # 5. 生成汇总
    df_summary = df_scores.groupby('model').mean()
    df_summary.to_csv(f'results/{task_type}_quality/quality_summary_{task_type}.csv')
```

## 数据验证

### 验证层次

数据验证分为三个层次：

#### 1. 模式验证 (Schema Validation)

验证数据结构是否符合预定义的模式：

```python
class DataValidator:
    """数据验证器"""
    
    def validate_schema(self, df: pd.DataFrame) -> Dict[str, Any]:
        """验证数据模式"""
        issues = []
        
        # 检查必需列
        required_cols = ['model_name', 'task_type', 'response_text']
        missing_cols = [col for col in required_cols if col not in df.columns]
        if missing_cols:
            issues.append(f"缺失必需列: {missing_cols}")
        
        # 检查数据类型
        if 'latency_s' in df.columns and not pd.api.types.is_numeric_dtype(df['latency_s']):
            issues.append("latency_s 应为数值类型")
        
        # 检查主键唯一性
        pk_cols = ['model_name', 'task_type', 'prompt_id', 'run_id']
        if all(col in df.columns for col in pk_cols):
            duplicates = df.duplicated(subset=pk_cols).sum()
            if duplicates > 0:
                issues.append(f"发现 {duplicates} 个重复主键")
        
        return {
            'valid': len(issues) == 0,
            'issues': issues
        }
```

#### 2. 完整性验证 (Completeness Validation)

验证数据的完整性：

```python
def validate_completeness(self, df: pd.DataFrame) -> Dict[str, Any]:
    """验证数据完整性"""
    report = {}
    
    # 缺失值统计
    missing_stats = df.isnull().sum()
    missing_pct = (missing_stats / len(df) * 100).round(2)
    report['missing_values'] = missing_pct[missing_pct > 0].to_dict()
    
    # 空字符串检查
    for col in df.select_dtypes(include=['object']).columns:
        empty_count = (df[col] == '').sum()
        if empty_count > 0:
            report[f'{col}_empty'] = empty_count
    
    # 覆盖率检查
    if 'model_name' in df.columns and 'task_type' in df.columns:
        coverage = df.groupby(['model_name', 'task_type']).size()
        report['coverage'] = coverage.to_dict()
    
    return report
```

#### 3. 一致性验证 (Consistency Validation)

验证数据的一致性和合理性：

```python
def validate_consistency(self, df: pd.DataFrame) -> Dict[str, Any]:
    """验证数据一致性"""
    issues = []
    
    # 数值范围检查
    if 'latency_s' in df.columns:
        if (df['latency_s'] < 0).any():
            issues.append("latency_s 存在负值")
        if (df['latency_s'] > 1000).any():
            issues.append("latency_s 存在异常大值 (>1000s)")
    
    if 'toks_per_s' in df.columns:
        if (df['toks_per_s'] < 0).any():
            issues.append("toks_per_s 存在负值")
        if (df['toks_per_s'] > 1000).any():
            issues.append("toks_per_s 存在异常大值 (>1000)")
    
    # 逻辑一致性检查
    if 'token_count' in df.columns and 'latency_s' in df.columns and 'toks_per_s' in df.columns:
        calculated_tps = df['token_count'] / df['latency_s']
        diff = abs(calculated_tps - df['toks_per_s'])
        inconsistent = (diff > 1).sum()
        if inconsistent > 0:
            issues.append(f"{inconsistent} 条记录的吞吐量计算不一致")
    
    return {
        'valid': len(issues) == 0,
        'issues': issues
    }
```

# 示例：在 CodeEvaluator 中添加新指标
class CodeEvaluator(BaseEvaluator):

        scores = {}
        
        # 现有指标...
        
        # 新增指标：代码注释率
        lines = generated.split('\n')

1. 创建新的评估器类（继承 `BaseEvaluator`）

3. 创建评估脚本
4. 更新数据管道的任务类型列表

```python
# 示例：添加对话任务评估器
class DialogueEvaluator(BaseEvaluator):
    """对话任务质量评估器"""
    
    def evaluate(self, generated: str, reference: str = None, 
                 context: Dict[str, Any] = None) -> Dict[str, float]:
        scores = {}

        scores['coherence'] = self._compute_coherence(generated)

                generated, context['history']
            )
        
        # 3. 回答完整性
        scores['completeness'] = self._compute_completeness(generated)
        
        return scores
```

### D. 性能优化建议

1. **使用 Parquet 格式**: 比 CSV 快 5-10 倍，节省 70-80% 空间
2. **启用缓存**: 常用查询自动缓存，避免重复计算
3. **批量处理**: 质量评估时使用批量计算，提升 GPU 利用率
4. **类型优化**: 使用 category 类型存储重复字符串，减少 70% 内存
5. **列选择**: 只加载需要的列，避免加载整个数据集
6. **分块处理**: 处理大文件时使用 chunksize 参数
7. **并行计算**: 使用多进程处理独立任务
